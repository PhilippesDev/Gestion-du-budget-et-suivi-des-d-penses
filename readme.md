# Gestion du Budget et Suivi des Dépenses

Application de gestion budgétaire et suivi des dépenses personnelles.

## Description

Cette application permet de gérer votre budget personnel et de suivre vos dépenses facilement. Elle offre une interface intuitive pour enregistrer vos revenus et dépenses, et visualiser votre situation financière.

## Fonctionnalités

- Enregistrement des revenus et dépenses
- Suivi des transactions
- Visualisation du budget
- Gestion des catégories de dépenses

## Installation

1. Copier le dossier dans le répertoire `htdocs` de XAMPP
2. Créer la base de données en exécutant le fichier `create_schema.sql`
3. Accéder à l'application via `http://localhost/Gestion-du-budget-et-suivi-des-d-penses`

## Structure du Projet

- **create_schema.sql** - Script SQL pour créer la structure de la base de données
- **db.php** - Fichier de connexion à la base de données
- **index.php** - Page principale de l'application
- **script.js** - Fichiers JavaScript pour les fonctionnalités dynamiques
- **styles.css** - Feuille de style pour la mise en forme

## Configuration

Modifiez les paramètres de connexion à la base de données dans le fichier `db.php` selon votre environnement.

## Utilisation

Accédez à l'application via votre navigateur web après installation et suivez l'interface pour gérer votre budget.
